== About This Part

This part of the TMForum API Developer's Handbook covers the API development loop: the repeating cycle of tasks that an API author performs to take an API from a JIRA work item through to a published, conformance-tested specification.

It is organised into two sections:

* *Runbooks* — step-by-step task guides, written in the order you will need them
* *Reference* — format specifications, option tables, and conventions to consult while working

If you are new to the project, read xref:runbooks/00-overview.adoc[The Development Loop Overview] first.

For first-time onboarding (accounts, permissions, tool installation), see xref:part1.adoc[Part 1: Initial Onboarding].

For starting a brand-new API (JIRA EPIC, TMF number, API profile), see Part 2: Starting a New API.
